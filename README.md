# Survivor – Space Shooter

بازی Broadcast خطی survivors با پایتون و PyGame.

## نمای کلی

- Arrow keys / WASD = حرکت
- Auto-fire + Space = شلیک
-inds, particles, wave system, multiplier و high scoreี
- Intro و page over

## بیهوده

- Python 3.10+
- PyGame

## نصب

```bash
python3 -m venv .venv
.venv/bin/python -m pip install pygame
```

## اجرای

```bash
.venv/bin/python survivor.py
```

یا

```bash
.venv/bin/python -m survivor
```

## کنترل‌ها

| کلید | عمل |
|------|-----|
| ← → ↑ ↓ یا WASD | حرکت کشتی |
| Space | شلیک دستی |
| ESC | خروج |

- کشتی با سایه و glow
